# 🔥 Australia Wildfire Analysis Project

This project analyzes and visualizes wildfire activity in Australia using Python (Pandas, Matplotlib, Seaborn, Folium). It includes data analysis, visual exploration, and insights for better wildfire management strategies.

---

## 📁 Project Structure

- **data/** → Raw wildfire dataset  
- **analysis/** → Jupyter notebook for all visualizations  
- **visuals/** → Graphs and questions from the project  
- **insights/** → Final insights and conclusions

---

## 📊 Tools Used

- Python (Pandas, NumPy, Matplotlib, Seaborn, Folium)
- Jupyter Notebook
- GitHub
